# Presentations Folder

Place your project presentation PDF files here.

## File Naming Convention
- Use lowercase with hyphens
- Match project ID for consistency
- Example: `nutrilink-healthygo.pdf`, `sekn-marketplace.pdf`

## How to Use
1. Export your PowerPoint/Google Slides as PDF
2. Place the PDF file in this folder
3. Add the presentation link in your project data:
   ```typescript
   links: {
     github: 'https://github.com/...',
     presentation: '/presentations/your-project.pdf'
   }
   ```
